# Continuous Learning Roadmap

This roadmap is separate from the product roadmap.

It answers:

> What should I learn next to move from Product Builder / Automation Designer toward Automation Engineer / AI Product Builder?

## 1. Automation Engineering
Primary platform:
**n8n Academy**

Focus:
- APIs;
- webhooks;
- subworkflows;
- error handling;
- AI workflows;
- testing;
- reusable patterns.

## 2. Software Engineering
Recommended sequence:

```text
JavaScript
→ TypeScript
→ HTTP / REST
→ Node.js
→ SQL
→ automated testing
→ software architecture
```

Use GitHub Skills to strengthen:
- Git;
- branches;
- pull requests;
- merge conflicts;
- repository management;
- GitHub Pages;
- introductory CI/CD.

## 3. Docker / Infrastructure
Recommended sequence:

```text
Container
→ Image
→ Volume
→ Network
→ Dockerfile
→ Compose
→ Logs / Healthcheck
→ Backup
→ Multi-container
→ Deployment
```

## 4. AI Systems
Priority:
**AI evaluation**

Recommended starting point:
DeepLearning.AI — Evaluating AI Agents.

Then:
- agents;
- RAG;
- LLMOps;
- monitoring;
- routing;
- tool use.

## 5. Product Design / Systems Design
Strengthen:
- discovery;
- research;
- service blueprints;
- system flows;
- metrics;
- experimentation;
- AI UX;
- internal tools;
- case storytelling.

## 6. Data / Reliability
Strengthen:
- SQL;
- relational modeling;
- constraints;
- indexes;
- migrations;
- transactions;
- idempotency;
- event logs;
- metrics;
- observability.

## Learning strategy

Do not collect courses.

Use:

```text
concept
→ exercise
→ apply in product
→ document
→ create portfolio evidence
```
