# Visual Assets

Add only sanitized assets.

Recommended:
- architecture infographic;
- system flow;
- state model;
- stack/logos graphic;
- planner diagram;
- reliability diagram;
- timeline;
- release-gate graphic;
- selected UI screenshots.

Before publishing screenshots:
- blur/remove user names;
- remove account IDs;
- remove browser tokens;
- remove private URLs;
- remove real content if not intended for publication.
