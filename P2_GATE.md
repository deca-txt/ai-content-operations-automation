# P2 Gate — Historical Scaffold Gate

P2 describes the original local-publication gate. It is retained as provenance; the current release status is documented in `docs/release-notes-v1.md` and `docs/reliability.md`.

P2 is complete when:

- the public repository scaffold exists locally;
- README and case documentation are coherent;
- production identifiers are absent;
- no credentials/secrets exist;
- no production database or raw execution artifacts exist;
- workflow folder contains only sanitized examples or remains empty;
- automated prepublish audit passes;
- manual sanitization checklist passes;
- repository metadata is approved.

## Important

Creating the local repository is part of P2.

Making it public on GitHub is a separate irreversible/public action and should happen only after manual review.
